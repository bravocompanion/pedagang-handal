# Pratinjau HTML

Jalankan dari direktori root repo dengan `python -m http.server 8000`, kemudian buka `http://localhost:8000/preview/`.

File `index.html` merupakan pratinjau v1.5.1 (Login Fix) yang mengarah ke Supabase khusus Pedagang Handal. Publishable key bersifat publik, tetapi seluruh akses data harus dibatasi dengan RLS.

Catatan: uji sign in/sign up nyata memerlukan provider email Supabase aktif. Jangan menggunakan login contoh untuk menyimpan data penting.
